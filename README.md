A lightweight and accurate deep learning system for classifying diseases in plant leaves using **MobileNetV2**. Trained on the extensive **PlantVillage** dataset, this project delivers impressive speed and precision in detecting various plant diseases from images.

---

## 🚀 Key Features

- 🧠 **Fast and Accurate Predictions:** Leverages **MobileNetV2 Transfer Learning** for efficient and high-performance disease classification.
- 🌱 **Multi-Disease Classification:** Identifies a wide range of diseases affecting plant leaves from image inputs.
- 🧪 **Streamlined Prediction Pipeline:** Offers a clean and straightforward process for testing the model with new, unseen images.
- 📂 **Organized Structure:** Features a well-structured directory layout for easy navigation and modification of the project.
- 📦 **Ready-to-Use Model:** Exports the trained model in the `.keras` format for seamless integration and deployment.
- 📸 **Local Image Support:** Easily test the model with images stored locally in the `test_images/` directory.
